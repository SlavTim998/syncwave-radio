# SyncWave 🎧

Публичное радио: у всех посетителей один и тот же трек, переключаемый администратором в реальном времени. Гостям регистрация не нужна.

## Возможности

- Общий эфир через Socket.IO; новое подключение подхватывает текущий трек с приблизительно нужной позиции.
- 2 встроенных синтезированных демонстрационных лупа, случайный старт и кнопка случайного выбора в админке.
- Администратор может выбрать трек, добавить прямую HTTPS-ссылку на аудио или загрузить MP3/OGG/WAV/M4A/WebM (до 25 МБ), удалять свои треки.
- Счётчик активных подключений для администратора (вкладки/соединения, **не уникальные люди**).
- Пароль хранится только в переменной окружения (не в репозитории), сравнение bcrypt, ограничение попыток входа, подписанные HttpOnly cookie.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
# Укажите надежные секреты в окружении (пример для macOS/Linux):
export ADMIN_PASSWORD='ВАШ_УНИКАЛЬНЫЙ_ДЛИННЫЙ_ПАРОЛЬ_ОТ_25_СИМВОЛОВ'
export SESSION_SECRET="$(node -e 'console.log(require("crypto").randomBytes(48).toString("hex"))')"
npm start
```

Откройте http://localhost:3000 . Админка — кнопка справа вверху. Для тестирования общего эфира откройте сайт в двух разных браузерах и нажмите «Подключиться к эфиру» в каждом.

## Публикация сайта (GitHub + Render)

1. Создайте **публичный репозиторий** на GitHub и загрузите весь исходный код (не загружайте `node_modules`, `.env`, каталог `data/uploads`). GitHub хранит код, **но GitHub Pages не запускает Node.js, Socket.IO и приём файлов**.
2. Зайдите на [Render](https://dashboard.render.com/), выберите **New → Blueprint** и подключите репозиторий. В проекте есть `render.yaml`.
3. В настройках сервиса установите `ADMIN_PASSWORD` — длинный случайный пароль **не короче 20 символов**. `SESSION_SECRET` сгенерируется автоматически.
4. Подтвердите платный экземпляр **Starter** с постоянным диском (нужен для сохранения загруженной музыки между перезапусками). По завершении развертывания Render выдаст публичный `https://...onrender.com`.
5. Откройте ссылку с другого устройства. Админка доступна по кнопке «Админка ↗».

Можно развернуть и на другом VPS/Node.js-хостинге с постоянным каталогом данных и поддержкой долгоживущих WebSocket-соединений. Запускайте **один экземпляр приложения**: состояние и подсчёт слушателей находятся в памяти процесса.

## Важные ограничения

- Браузеры запрещают запуск звука без жеста пользователя. Посетителю надо один раз нажать «Подключиться к эфиру».
- Прямая внешняя HTTPS-ссылка должна действительно отдавать аудио и разрешать воспроизведение в браузере. Страницы YouTube, Spotify, SoundCloud и ссылки со специальными ограничениями не поддерживаются.
- Музыку размещайте только при наличии прав на её публичное воспроизведение.
- Синхронизация приблизительная (в пределах сетевых задержек), не sample-perfect. Встроенные лупы зациклены; для других треков включён loop, пока администратор не выберет новый трек.
- Загрузки проверяются по расширению и ограничены размером; для серьёзной публичной эксплуатации следует дополнительно добавить проверку сигнатуры файлов, антивирусное сканирование, CSRF-защиту, резервное копирование, внешнее хранилище аудио и Redis-адаптер при масштабировании.
- Не публикуйте в GitHub пароль/секрет из переменных окружения.
